# Tholen historische audiowandeling – routekaart versie

Deze versie gebruikt de aangeleverde GPS-opname `Gps_Audio_Stadswandeling_.gpx` als route voor de kaart.

De taalkeuze staat bovenaan de site als afzonderlijke knoppen met de vlag van het betreffende land:
🇳🇱 🇬🇧 🇩🇪 🇫🇷 🇮🇹 🇪🇸 🇵🇹 🇩🇰 🇳🇴 🇸🇪 🇵🇱

De 15 haltes zijn als genummerde punten op de GPS-route geplaatst. De tekstbestanden uit de bestaande productieversie blijven behouden.

De kaart gebruikt OpenStreetMap via Leaflet; daarvoor is internet nodig wanneer de site online wordt geopend.
